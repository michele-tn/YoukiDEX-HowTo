Before you install

Know what
YoukiDEX needs.

The basic desktop works with standard Android permissions. Recent apps, display controls and other system-level features need one additional setup step.

01 Android 11+Version 2.7 requires API 30 or newer
02 AccessibilityLets the dock follow system and window events
03 Overlay accessAllows the dock to remain above other apps
04 Shizuku / ADBRecommended for privileged desktop controls

First-time setup

Up and running,
step by step.

Start with the standard permissions, test the dock, then add elevated access only if you need the advanced controls.

01

Install the current APK

Download the latest package from the project’s GitHub Releases page. Android may ask you to allow installs from your browser or file manager.

02

Grant the core permissions

Open YoukiDEX and follow the prompts for overlay, Accessibility, usage access and notification access. Each permission controls a separate part of the desktop.

03

Add the Quick Settings tile

Edit Android’s Quick Settings panel, find the YoukiDEX tile and drag it into the active area. Use this tile to enter or leave desktop mode.

04

Choose your layout

Open YoukiDEX settings to select a centered floating dock or the classic edge-pinned layout. Configure colors, transparency, icon packs and your preferred wallpaper app.

Optional elevated access

Unlock the
system controls.

Shizuku is the most convenient route. Direct ADB commands are also available when you prefer a one-time wired setup.

adb devices adb shell pm grant \ com.youki.dex \ android.permission.WRITE_SECURE_SETTINGS adb shell appops set \ com.youki.dex \ GET_USAGE_STATS allow

Secure settingsWRITE_SECURE_SETTINGS enables display-size and other protected system controls.

Recent applicationsGET_USAGE_STATS lets the desktop identify recently used and running apps.

AlternativeShizuku provides privileged shell access without leaving wireless ADB connected.

Common fixes

When the dock
doesn’t behave.

  1. 1Dock missing after restart: enable auto-start and remove battery restrictions for YoukiDEX.
  2. 2Accessibility blocked: on recent Android versions, install through ADB or allow restricted settings for the app.
  3. 3Floating windows unavailable: enable resizable activities and freeform windows in Developer Options, then reboot.
  4. 4Portrait-only apps: some applications hard-code their orientation and cannot be forced to landscape without system privileges.
