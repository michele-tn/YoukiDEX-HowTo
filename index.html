Desktop toolkit

What YoukiDEX
adds to Android.

YoukiDEX is a desktop layer rather than a cosmetic launcher. Its services connect the dock, windows, notifications and system controls while your existing launcher remains available underneath.

Dock

Persistent taskbar

Keep pinned and running applications visible over other apps. Choose a centered KDE-style dock or a classic edge-pinned layout.

Windows

Freeform applications

Open supported applications in resizable floating windows, minimize them from the taskbar and restore them with another tap.

Navigation

App drawer and shortcuts

Search and sort installed applications, apply third-party icon packs and long-press icons to open Android deep shortcuts.

System

Tray and quick controls

See battery, Wi-Fi, Bluetooth and audio status. Use the quick panel for brightness, volume and notification management.

Workflow

Keyboard and Multi-Display

Use hardware keyboard shortcuts, hot corners and multiple connected displays for a more conventional desktop workflow.

Personalization

Material You and profiles

Adjust colors, bubble opacity, dock transparency, sound events, profile picture and the wallpaper shortcut.

Performance

Resource monitor

Display live CPU and RAM information in the taskbar while working across applications.

Advanced

Root and Shizuku

Use automatic Magisk or KernelSU detection, or grant privileged shell access through Shizuku without keeping ADB connected.

First-time setup

Up and running,
step by step.

Start with the standard permissions, test the dock, then add elevated access only if you need the advanced controls.

Install the current APK

Download the latest package from the project’s GitHub Releases page. Android may ask you to allow installs from your browser or file manager.

Grant the core permissions

Open YoukiDEX and follow the prompts for overlay, Accessibility, usage access and notification access. Each permission controls a separate part of the desktop.

Add the Quick Settings tile

Edit Android’s Quick Settings panel, find the YoukiDEX tile and drag it into the active area. Use this tile to enter or leave desktop mode.

Choose your layout

Open YoukiDEX settings to select a centered floating dock or the classic edge-pinned layout. Configure colors, transparency, icon packs and your preferred wallpaper app.

Permission reference

What each
permission does.

YoukiDEX asks for broad Android access because it coordinates windows and system UI. Grant only the functions you intend to use.

SYSTEM_ALERT_WINDOW

Display over other apps

Draws the dock, panels and desktop controls above normal application windows.

ACCESSIBILITY_SERVICE

Window awareness

Detects system UI and application-window events so the dock can react to foreground changes.

PACKAGE_USAGE_STATS

Recent and running apps

Provides the usage information required to populate recent-app and running-app views.

WRITE_SECURE_SETTINGS

Protected display controls

Enables system-level settings such as display-size adjustments. Android requires ADB, Shizuku or root to grant this access.

QUERY_ALL_PACKAGES

Complete app drawer

Lets YoukiDEX discover installed applications and present them in the searchable drawer.

NOTIFICATION_LISTENER

Notification panel

Reads active notifications for the desktop panel and allows supported notifications to be dismissed.

Optional elevated access

Unlock the
system controls.

Shizuku is the most convenient route. Direct ADB commands are also available when you prefer a one-time wired setup.

adb devices adb shell pm grant \ com.youki.dex \ android.permission.WRITE_SECURE_SETTINGS adb shell appops set \ com.youki.dex \ GET_USAGE_STATS allow

Secure settingsWRITE_SECURE_SETTINGS enables display-size and other protected system controls.

Recent applicationsGET_USAGE_STATS lets the desktop identify recently used and running apps.

Common fixes

When the dock
doesn’t behave.

  • Dock missing after restart

    Enable auto-start and remove battery restrictions for YoukiDEX.

  • Accessibility blocked

    On recent Android versions, install through ADB or allow restricted settings for the app.

  • Floating windows unavailable on RedMagic or ZTE

    Enable “Force activities to be resizable” and “Enable freeform windows” in Developer Options. If the device provides Settings → Display → Desktop Mode, enable it, then reboot.

  • Portrait-only apps

    Some applications hard-code their orientation and cannot be forced to landscape without system privileges.

Questions and answers

Before you
start debugging.

Most setup problems come from Android security restrictions, manufacturer battery management or missing elevated permissions.

Must YoukiDEX replace my current launcher?

No. Its normal operating mode is a system overlay, so the existing launcher remains untouched. Since version 2.5, YoukiDEX can also be selected as the default home application if you want it to load automatically.

Why does the dock disappear after a reboot?

Confirm that the YoukiDEX Accessibility Service is still enabled. Then allow auto-start and exclude the app from battery optimization or background-process restrictions imposed by the device manufacturer.

Why does display-size control have no effect?

That control requires WRITE_SECURE_SETTINGS. Start Shizuku and approve YoukiDEX when prompted, grant the permission through ADB, or use root access. Android does not expose this setting to ordinary third-party apps.

Why is Accessibility blocked on Android 13, 14 or 15?

Android may classify a sideloaded APK as a restricted application. Open the app information screen and allow restricted settings when that option is available. Alternatively, install the APK directly with adb install YoukiDex.apk.

Do I need Shizuku?

No for the basic overlay and dock. It is recommended for secure settings and privileged shell operations because it avoids maintaining a wireless ADB connection after the initial Shizuku setup.

What should Android 10 users install?

Use YoukiDEX 2.6. Starting with version 2.7, the minimum supported version is Android 11 because the project depends on more reliable overlay, freeform-window and Shizuku behavior introduced on newer Android releases.

Are Android 16 overlay issues known?

Yes. Android 16 introduced stricter overlay touch and inset behavior. The upstream project reports that core functions remain usable while remaining edge cases are addressed in later updates.

Why is there no Google Play version?

The application relies on sensitive permissions that are not suitable for its planned Play Store distribution model. Obtain the APK from the official GitHub Releases page and review the release notes before installing.

Project notes

Scope, credits
and expectations.

Project lineage

YoukiDEX is based on Smart Dock and has been extensively modified by mrYouki. The project also credits the wider open-source Android community.

Not currently planned

Real-time background blur, iOS support, cloud settings sync and multi-user support are outside the project scope. Task Manager, dock widgets and a built-in file manager are listed as planned rather than available.

Independent software

YoukiDEX is an independent open-source project and is not affiliated with or endorsed by a device manufacturer or platform company.

License and source

The upstream repository is licensed under GPL-3.0. Use the official repository for source code, issue reporting, releases and authoritative project information.
